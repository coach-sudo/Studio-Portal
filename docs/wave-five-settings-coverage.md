# Wave 5 Settings coverage

Classification: **verified** means an existing source/command/consumer connection is retained and its earlier evidence is reused; **repaired** identifies a connection changed in Wave 5 and covered by the focused local checks; **external** means the portal cannot configure or prove the capability itself. Final protected-browser/cross-session acceptance remains pending, so this matrix is not a claim of completed hosted verification.

Coach Settings URLs are `/coach/settings?panel=profile|pricing|booking|communications|integrations|access|data`. Legacy `studio`, `portal`, `popup` and `email` identifiers remain supported. Student/guardian Settings retain profile, preferences, security and permitted billing anchors.

Corrective release: `wave-five-corrective-release.md` records the newly reproduced persistence and RLS defects. Earlier source-only checks did not prove hosted image save/readback. The corrective PR must attach upload, reload, fresh-session, replacement/removal and exact cleanup evidence before publication.

The coach save chain is the authoritative studio read → existing `settings.update` boundary → changed-field patch → `command_patch_studio_settings` → independent identity/booking reads. Patches hold the studio lock, preserve unrelated nested fields, reject conflicting changed leaves and write audit plus replay receipt atomically. Student/contact commands retain expected-version checks and merge authorized preference fields.
