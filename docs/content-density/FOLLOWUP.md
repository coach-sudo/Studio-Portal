## Package pricing behavior

- Linked package offers derive from the current service price, session count, delivery adjustment, and existing percentage/fixed discount. No manual recalculation is needed to update displayed or charged new-purchase prices.
- Authenticated student purchases and coach assignments use that student's enabled, currently effective service-specific rate and delivery adjustment. The snapshot mapper retains saved student location adjustments so the displayed and server quotes agree. Disabled, inactive, future, expired, other-student, other-service, and other-studio rules are excluded. Rate lookup errors stop checkout rather than silently charging a public or stale price.
- Coach catalog, student offer/purchase dialogs, assignment choices, and defaults for newly added invoice package lines use current quotes. Existing invoice lines and purchased packages retain their snapshots. Explicit coach invoice edits remain available.
- The server independently recalculates before purchase/assignment and rejects a changed displayed price or currency before creating a purchase. Stripe uses an immutable price matching that quote, reusing an existing match or creating a new price; shared billing options and existing Stripe subscriptions are not repriced.
- Balance-triggered renewals charge the original purchased package price. Paid renewal webhooks grant the original purchased quantity rather than an edited catalog quantity.
- Public offers and gifts use studio pricing. Private student rates are not exposed through an anonymous recipient-email lookup; the student dialog labels its gift action “Gift at studio pricing.”
- Gift claims retain the signed paid checkout quote, including delayed delivery after a price edit. Migration `20261008120000_preserve_package_gift_price.sql` replaces only the existing claim-function body, reading existing webhook receipts. It adds no tables or columns and preserves the function signature, authorization, availability checks, and idempotency. Already claimed gifts return unchanged. Apply through the normal reviewed migration process; no database was changed during this work.
- Standalone legacy packages without a source service keep their stored price. A linked offer with unavailable source pricing is not advertised as a purchasable stale quote.
