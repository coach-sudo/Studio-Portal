The local demo has no guardian role or genuinely free service, so those must be judged from the authenticated fixture run, not inferred from demo data.

## Review of the two post-report changes at `4413fc04`

- Timezone aliases are appropriate: Eastern, Central, Mountain, Pacific, Alaska, and Hawaii search the canonical IANA zones, while city/region search and DST-aware labels remain intact. All six aliases now have unit regression coverage.
- Sparse actor styling was appropriate in intent, but `.actor-public-hero` in `cohesion.css` had higher-priority later rules that kept the 720 px full-profile hero. The scoped override in this PR makes the compact desktop/mobile layout actually render. The published no-headshot fixture has a deployed CSS assertion.

## Scoped review fixes

1. Make sparse actor hero overrides effective at both breakpoints.
2. Hide empty recurring plans and empty active-package section; preserve populated states.
3. Reflow mobile lesson history and receipt amounts, correct the month-only date tile, increase coach roster metadata to 12 px, and keep the mobile Inbox composer above navigation.
4. Ensure coach lesson facts styling loads on its own route, dark/light neutral status pills meet contrast, the mobile settings index does not cut off labels, and a focused timezone field scrolls clear of the fixed bottom navigation so its options remain usable.
5. Expand timezone alias tests and add desktop/mobile visual screenshots and affected mobile axe assertions. The free booking screenshot uses only the deterministic `e2e-` fixture.

## Deliberately deferred

- A changed-Meet-link state lacks a durable signal.
- Guardian multi-student switching requires access-model changes.
- The actor editor's long-form structure and mobile horizontal section/tab indexes are product follow-ups, not regressions or PR6 blockers.
- A naturally emitted PWA install event requires a compatible browser/session and cannot be asserted from the demo alone; component coverage remains the deterministic gate.

## PR7 recommendations only — no PR7 work started

- Analyze and split the entry JavaScript and global stylesheet: both currently pass their failure budgets but exceed warning thresholds (125,066 B and 24,884 B gzip respectively). The stylesheet is close to the 25,000 B failure budget.
- Consolidate duplicate actor styling in `styles.css` / `cohesion.css` so a later broad rule cannot silently override a feature-specific layout again.
- Record route-level transfer/request/render figures before optimization and rerun visual/axe evidence after CSS extraction. Preserve the new mobile Inbox safe-area geometry and sparse actor breakpoints as regression baselines.
